# Contact photographs: sources and licences

The nine photos the LLM planners receive in the airspace-challenge and disguise runs, one per contact. Built by `prepare_stimuli.py`
from the originals in `sources.json` (fetched with `--fetch`): readable text on the objects removed (masked and filled by harmonic
interpolation of the surrounding pixels), then 4:3 crop, 640x480, JPEG quality 90, no metadata. No image
contains readable text. Licences checked 2026-10-20/21 on each source page. Third-party material: these
photos are not covered by the licence of the code in this repository; each is used under its own licence.
